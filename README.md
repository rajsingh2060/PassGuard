
# PassGuard - Password Strength Checker

## About the Project
PassGuard is a beginner-friendly Python command-line
application that checks password strength.

It evaluates password length, lowercase letters,
uppercase letters, numbers, and special symbols.

It provides a score and suggestions to improve
password strength.

## Features
- Checks password length.
- Detects lowercase letters.
- Detects uppercase letters.
- Detects numbers.
- Detects special symbols.
- Rates passwords as Weak, Medium, or Strong.
- Provides improvement suggestions.
- Hides password input using Python getpass.

## Technologies Used
- Python 3
- getpass module
- string module

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run the following command:

python passguard.py
